# Lab 6 Bash Scripting and Automation

Objective

This project focused on developing automation capabilities using Bash scripting to streamline reconnaissance, system monitoring, and security data collection. The primary objective was to create functional scripts that automate repetitive tasks, imrpove efficiency, and simulate workflows common in SOC and penetration testing environments.

Skills Learned

- Writing Bash scripts with variables, loops, and conditionals for automation
- Automating reconnaissance tasks such as ping sweeps and port checks
- Building interactive scripts that accept user input for dynamic scanning
- Processing system outputs and logs into structured analysis reports
- Understanding how automation accelerates security monitoring and investigations

Tools Used

- Bash scripting for automation and repeatable workflows
- nmap, ping, nc and system commands for data collection
- Linux environment for executing, testing, and debugging scripts
- Custom output logs and generated reports to support analysis
